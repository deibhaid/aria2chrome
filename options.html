📖 Quick Setup Guide

  1. Install and run aria2c with RPC enabled: aria2c --enable-rpc --rpc-listen-all=true
  2. If using a secret token, add: --rpc-secret=YOUR_SECRET
  3. Configure the RPC URL above (default: http://localhost:6800/jsonrpc)
  4. Test the connection and save your settings

💡 Tips

  • The extension will intercept clicks on video file links (.mp4, .mkv, etc.)
  • Downloads will automatically resume if they fail or are interrupted
  • Use the popup to monitor download progress and manage your queue
